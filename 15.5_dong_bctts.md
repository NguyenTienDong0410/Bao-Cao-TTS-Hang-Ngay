# I. Cài đặt FTP Server trên Ubuntu với vsftpd

**1. Giới thiệu vsftpd**
vsftpd (Very Secure FTP Daemon) là FTP server phổ biến nhất trên Linux, được biết đến với tính bảo mật cao, hiệu năng tốt và dễ cấu hình. Đây là lựa chọn mặc định trên nhiều bản phân phối Ubuntu/Debian.

Tham số	Giá trị	Giải thích
Phần mềm	vsftpd	Very Secure FTP Daemon
Hệ điều hành	Ubuntu 20.04 / 22.04	Hỗ trợ cả phiên bản LTS
Port mặc định	21 (Control), 20 (Data)	FTP standard ports
Passive ports	50000 – 50100	Có thể tùy chỉnh
File cấu hình	/etc/vsftpd.conf	File cấu hình chính

**2. Cài đặt vsftpd**
Bước 1: Cập nhật hệ thống và cài đặt vsftpd
Mở Terminal và chạy các lệnh sau với quyền root hoặc sudo:

# Cập nhật danh sách gói
sudo apt update && sudo apt upgrade -y

# Cài đặt vsftpd
sudo apt install vsftpd -y

# Kiểm tra trạng thái dịch vụ
sudo systemctl status vsftpd

Bước 2: Sao lưu file cấu hình gốc
# Tạo bản sao dự phòng file cấu hình gốc
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.backup

# Mở file cấu hình để chỉnh sửa
sudo nano /etc/vsftpd.conf

3. Cấu hình vsftpd (File /etc/vsftpd.conf)
Chỉnh sửa file cấu hình với các thiết lập sau. Tìm và thay đổi các dòng tương ứng, hoặc thêm mới nếu chưa có:

3.1 Cấu hình cơ bản
# Tắt kết nối ẩn danh (nên tắt trong môi trường sản xuất)
anonymous_enable=NO

# Cho phép đăng nhập bằng local user
local_enable=YES

# Cho phép ghi file (upload)
write_enable=YES

# Đặt umask cho local user (022 = file 644, thư mục 755)
local_umask=022

# Hiển thị thông điệp chào mừng
dirmessage_enable=YES

# Sử dụng thời gian địa phương
use_localtime=YES

# Bật ghi log
xferlog_enable=YES
xferlog_file=/var/log/vsftpd.log

3.2 Cấu hình Passive Mode (quan trọng)
Passive Mode là chế độ bắt buộc khi FTP client nằm sau NAT/Firewall. Thêm các dòng sau vào cuối file cấu hình:

# === BẬT PASSIVE MODE ===
pasv_enable=YES

# Địa chỉ IP công khai của FTP server
# (Thay bằng IP thực của server hoặc domain)
pasv_address=192.168.1.100

# Dải port cho passive data connection
pasv_min_port=50000
pasv_max_port=50100

<img width="564" height="284" alt="image" src="https://github.com/user-attachments/assets/d6c6225a-5a7b-4da3-8080-e78c5ed404a9" />

# === BẢO MẬT ===
# Giới hạn user trong thư mục home (chroot)
chroot_local_user=YES
allow_writeable_chroot=YES

# Danh sách user được phép truy cập
userlist_enable=YES
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO

QUAN TRỌNG	pasv_address phải là IP public của server. Nếu dùng trong mạng LAN, dùng IP LAN. Nếu trên cloud (AWS, GCP...), dùng Elastic IP hoặc IP public.

Tham số	Giá trị	Giải thích
pasv_enable=YES	Bật Passive Mode	Cho phép client mở kết nối data từ phía client
pasv_address	IP public của server	Client dùng địa chỉ này để kết nối data
pasv_min_port	50000	Port bắt đầu của dải passive
pasv_max_port	50100	Port kết thúc (101 ports)
chroot_local_user	YES	Giới hạn user trong thư mục home

4. Tạo FTP User và Thư mục


1	Tạo user FTP	sudo useradd -m -d /home/ftpuser -s /bin/bash ftpuser



2	Đặt mật khẩu	
sudo passwd ftpuser  →  nhập mật khẩu khi được yêu cầu

3	Tạo thư mục FTP	sudo mkdir -p /home/ftpuser/ftp/uploads


4	Phân quyền thư mục gốc	sudo chown nobody:nogroup /home/ftpuser/ftp


5	Phân quyền uploads	sudo chown ftpuser:ftpuser /home/ftpuser/ftp/uploads
6	Thêm user vào danh sách	echo 'ftpuser' | sudo tee -a /etc/vsftpd.userlist
7	Khởi động lại vsftpd	sudo systemctl restart vsftpd

GHI CHÚ	Thư mục ftp (gốc) cần có quyền nobody để chroot hoạt động. Chỉ thư mục uploads mới có quyền ghi cho ftpuser.

5. Cấu hình Firewall (UFW)
# Mở port FTP control
sudo ufw allow 21/tcp

# Mở dải port passive mode
sudo ufw allow 50000:50100/tcp

# Kiểm tra quy tắc firewall
sudo ufw status verbose

# Tải lại UFW
sudo ufw reload

# II. FTP SERVER TRÊN WINDOWS (IIS)


1. Giới thiệu IIS FTP trên Windows
Windows tích hợp sẵn FTP Server thông qua Internet Information Services (IIS). Đây là giải pháp FTP chính thức của Microsoft, phù hợp với môi trường doanh nghiệp sử dụng Active Directory và Windows Server.

Tham số	Giá trị	Giải thích
Hệ điều hành	Windows Server 2016/2019/2022	Hỗ trợ cả Windows 10/11 Pro
FTP Engine	IIS FTP Service	Tích hợp sẵn trong Windows
Port mặc định	21 (Control), 20 (Data)	FTP standard
Passive ports	Tùy chỉnh trong IIS	Thường 50000–50100
Giao diện quản trị	IIS Manager (inetmgr)	Giao diện đồ họa GUI

2. Cài đặt IIS FTP Service
Phương pháp 1: Cài đặt qua Server Manager (Windows Server)
Bước	Thao tác	Chi tiết / Lệnh thực hiện
1	Mở Server Manager	Nhấn Start → Server Manager
2	Add Roles	Nhấn 'Add roles and features'
3	Chọn Role	Chọn 'Web Server (IIS)' trong danh sách Server Roles

4	FTP Server	Mở rộng 'Web Server (IIS)' → 'FTP Server', tích chọn 'FTP Service'
5	Xác nhận	Nhấn 'Install' và chờ quá trình cài đặt hoàn tất

# Chạy PowerShell với quyền Administrator

# Đặt dải port passive cho FTP
Set-WebConfiguration /system.ftpServer/firewallSupport -Value @{

    highDataChannelPort = 50100

Restart-Service ftpsvc

TỔNG KẾT VÀ SO SÁNH

So sánh vsftpd (Ubuntu) và IIS FTP (Windows)
Tiêu chí	vsftpd (Ubuntu)	IIS FTP (Windows)
Hệ điều hành	Ubuntu / Debian / RHEL	Windows Server / 10 / 11 Pro
Chi phí	Miễn phí (Open Source)	Tích hợp sẵn trong Windows
Giao diện quản trị	File cấu hình (CLI)	IIS Manager (GUI) + CLI
Hiệu năng	Rất cao, nhẹ	Tốt, có GUI overhead
Bảo mật	Rất cao với SSL/TLS	Tốt, tích hợp AD
Passive Mode	Cấu hình trong .conf	IIS Manager + PowerShell
Phù hợp	Server Linux, Cloud, DevOps	Môi trường doanh nghiệp Windows
