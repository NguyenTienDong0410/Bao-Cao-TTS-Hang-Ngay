## I. Cài đặt FTP Server trên Ubuntu với vsftpd

### 1. Giới thiệu vsftpd

vsftpd (Very Secure FTP Daemon) là FTP server phổ biến nhất trên Linux, được biết đến với tính bảo mật cao, hiệu năng tốt và dễ cấu hình. Đây là lựa chọn mặc định trên nhiều bản phân phối Ubuntu/Debian.

FTP (File Transfer Protocol) hoạt động theo mô hình client-server, sử dụng hai kênh kết nối riêng biệt: kênh điều khiển (control channel) trên port 21 để gửi lệnh, và kênh dữ liệu (data channel) trên port 20 hoặc các port passive để truyền file. vsftpd hỗ trợ cả hai chế độ Active và Passive Mode, trong đó Passive Mode được khuyến nghị khi client nằm sau NAT hoặc Firewall.

| Tham số | Giá trị | Giải thích |
|---|---|---|
| Phần mềm | vsftpd | Very Secure FTP Daemon |
| Hệ điều hành | Ubuntu 20.04 / 22.04 | Hỗ trợ cả hai phiên bản LTS |
| Port mặc định | 21 (Control), 20 (Data) | FTP standard ports |
| Passive ports | 50000 – 50100 | Có thể tùy chỉnh theo nhu cầu |
| File cấu hình | /etc/vsftpd.conf | File cấu hình chính của vsftpd |

---

### 2. Cài đặt vsftpd

#### Bước 1: Cập nhật hệ thống và cài đặt vsftpd

Mở Terminal và chạy các lệnh sau với quyền root hoặc sudo:

```bash
# Cập nhật danh sách gói và nâng cấp các gói hiện có
sudo apt update && sudo apt upgrade -y

# Cài đặt vsftpd
sudo apt install vsftpd -y

# Kiểm tra trạng thái dịch vụ sau khi cài đặt
sudo systemctl status vsftpd
```

![Trạng thái dịch vụ vsftpd sau khi cài đặt](https://github.com/user-attachments/assets/47adddbf-b47f-4587-80aa-5a8cd2a3700d)

> **Lưu ý:** Nếu trạng thái hiển thị `active (running)` màu xanh lá, vsftpd đã được cài đặt và đang chạy thành công. Nếu dịch vụ chưa tự khởi động, dùng lệnh `sudo systemctl start vsftpd` và `sudo systemctl enable vsftpd` để bật tự khởi động cùng hệ thống.

#### Bước 2: Sao lưu file cấu hình gốc

Trước khi chỉnh sửa, cần tạo bản sao lưu file cấu hình gốc để có thể phục hồi nếu xảy ra lỗi:

```bash
# Tạo bản sao dự phòng file cấu hình gốc
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.backup

# Mở file cấu hình để chỉnh sửa
sudo nano /etc/vsftpd.conf
```

### 3. Cấu hình vsftpd (File /etc/vsftpd.conf)

Chỉnh sửa file cấu hình với các thiết lập sau. Tìm và thay đổi các dòng tương ứng, hoặc thêm mới nếu chưa có.

#### 3.1. Cấu hình cơ bản

```bash
# Tắt kết nối ẩn danh (nên tắt trong môi trường sản xuất)
anonymous_enable=NO

# Cho phép đăng nhập bằng local user (tài khoản hệ thống)
local_enable=YES

# Cho phép ghi file (upload)
write_enable=YES

# Đặt umask cho local user (022 = file 644, thư mục 755)
local_umask=022

# Hiển thị thông điệp chào mừng khi vào thư mục
dirmessage_enable=YES

# Sử dụng thời gian địa phương thay vì UTC
use_localtime=YES

# Bật ghi log các phiên truyền file
xferlog_enable=YES
xferlog_file=/var/log/vsftpd.log
```

![Cấu hình cơ bản trong file vsftpd.conf](https://github.com/user-attachments/assets/d5858bd1-f47d-47bf-903c-807acac5bd67)

![Kết quả cấu hình cơ bản](https://github.com/user-attachments/assets/541b93ce-1de9-4e52-ac8c-e2feb579f617)

#### 3.2. Cấu hình Passive Mode

Passive Mode là chế độ bắt buộc khi FTP client nằm sau NAT hoặc Firewall. Trong chế độ này, server sẽ thông báo cho client biết địa chỉ IP và dải port để client chủ động mở kết nối dữ liệu, thay vì server cố gắng kết nối ngược về phía client như trong Active Mode.

Thêm các dòng sau vào cuối file cấu hình:

```bash
# === BẬT PASSIVE MODE ===
pasv_enable=YES

# Địa chỉ IP công khai của FTP server
# (Thay bằng IP thực của server hoặc tên miền)
pasv_address=192.168.1.100

# Dải port cho passive data connection
pasv_min_port=50000
pasv_max_port=50100
```

![Cấu hình Passive Mode](https://github.com/user-attachments/assets/d6c6225a-5a7b-4da3-8080-e78c5ed404a9)

```bash
# === BẢO MẬT ===
# Giới hạn user trong thư mục home của họ (chroot jail)
chroot_local_user=YES
allow_writeable_chroot=YES

# Kích hoạt danh sách user được phép truy cập FTP
userlist_enable=YES
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO
```

> **Quan trọng:** `pasv_address` phải là IP public của server. Nếu dùng trong mạng LAN, dùng IP LAN. Nếu triển khai trên cloud (AWS, GCP, Azure...), cần dùng Elastic IP hoặc IP public được cấp phát. Khai báo sai địa chỉ này sẽ khiến client không thể thiết lập kết nối dữ liệu trong Passive Mode.

| Tham số | Giá trị | Giải thích |
|---|---|---|
| pasv_enable | YES | Bật Passive Mode |
| pasv_address | IP public của server | Client dùng địa chỉ này để mở kết nối dữ liệu |
| pasv_min_port | 50000 | Port bắt đầu của dải passive |
| pasv_max_port | 50100 | Port kết thúc (tổng cộng 101 port) |
| chroot_local_user | YES | Giới hạn user trong thư mục home (chroot jail) |
| allow_writeable_chroot | YES | Cho phép ghi vào thư mục chroot |

### 4. Tạo FTP User và Thư mục

Sau khi cấu hình xong file vsftpd.conf, thực hiện lần lượt các bước sau để tạo tài khoản FTP và cấu trúc thư mục phù hợp:

| Bước | Thao tác | Lệnh thực hiện |
|---|---|---|
| 1 | Tạo user FTP | `sudo useradd -m -d /home/ftpuser -s /bin/bash ftpuser` |
| 2 | Đặt mật khẩu | `sudo passwd ftpuser` → nhập mật khẩu khi được yêu cầu |
| 3 | Tạo thư mục FTP | `sudo mkdir -p /home/ftpuser/ftp/uploads` |
| 4 | Phân quyền thư mục gốc | `sudo chown nobody:nogroup /home/ftpuser/ftp` |
| 5 | Phân quyền thư mục uploads | `sudo chown ftpuser:ftpuser /home/ftpuser/ftp/uploads` |
| 6 | Thêm user vào danh sách | `echo 'ftpuser' \| sudo tee -a /etc/vsftpd.userlist` |
| 7 | Khởi động lại vsftpd | `sudo systemctl restart vsftpd` |

> **Ghi chú:** Thư mục `ftp` (gốc) cần được sở hữu bởi `nobody:nogroup` để cơ chế chroot hoạt động đúng — vsftpd yêu cầu thư mục chroot root không được phép ghi bởi user đăng nhập. Chỉ thư mục `uploads` bên trong mới cần phân quyền ghi cho `ftpuser`.

### 5. Cấu hình Firewall (UFW)

UFW (Uncomplicated Firewall) cần được cấu hình để cho phép lưu lượng FTP đi qua. Cần mở cả port điều khiển (21) lẫn toàn bộ dải port passive (50000–50100):

```bash
# Mở port FTP control
sudo ufw allow 21/tcp

# Mở dải port passive mode
sudo ufw allow 50000:50100/tcp

# Kiểm tra các quy tắc firewall hiện tại
sudo ufw status verbose

# Tải lại UFW để áp dụng các thay đổi
sudo ufw reload
```

### 7. Kiểm tra và Xử lý lỗi

#### Các lệnh kiểm tra trạng thái

```bash
# Kiểm tra vsftpd có đang chạy không
sudo systemctl status vsftpd

# Xem log theo thời gian thực để debug
sudo tail -f /var/log/vsftpd.log

# Kiểm tra port 21 có đang lắng nghe không
sudo ss -tlnp | grep :21
```

#### Bảng lỗi thường gặp và cách xử lý

| Lỗi gặp phải | Nguyên nhân | Cách xử lý |
|---|---|---|
| `500 OOPS: refusing to run with writable root` | Thư mục chroot root có quyền ghi cho user | Thêm `allow_writeable_chroot=YES` vào vsftpd.conf hoặc đặt lại quyền thư mục gốc về `nobody:nogroup` |
| Passive mode timeout / Connection refused | Firewall chặn dải port passive hoặc `pasv_address` sai | Kiểm tra UFW đã mở cổng 50000–50100, đảm bảo `pasv_address` trùng với IP public của server |
| `530 Login incorrect` | User chưa được thêm vào danh sách cho phép | Kiểm tra user đã có trong `/etc/vsftpd.userlist` chưa, đảm bảo `userlist_deny=NO` |

## II. FTP Server trên Windows (IIS)

### 1. Giới thiệu IIS FTP trên Windows

Windows tích hợp sẵn FTP Server thông qua Internet Information Services (IIS). Đây là giải pháp FTP chính thức của Microsoft, phù hợp với môi trường doanh nghiệp sử dụng Active Directory và Windows Server. IIS FTP cung cấp giao diện đồ họa (GUI) để quản trị, đồng thời hỗ trợ cấu hình bằng PowerShell cho tự động hóa.

| Tham số | Giá trị | Giải thích |
|---|---|---|
| Hệ điều hành | Windows Server 2016/2019/2022 | Hỗ trợ cả Windows 10/11 Pro |
| FTP Engine | IIS FTP Service | Tích hợp sẵn trong Windows |
| Port mặc định | 21 (Control), 20 (Data) | FTP standard |
| Passive ports | Tùy chỉnh trong IIS | Thường dùng dải 50000–50100 |
| Giao diện quản trị | IIS Manager (inetmgr) | Giao diện đồ họa GUI |

### 4. Cấu hình Passive Mode trên IIS

#### Bước 1: Cấu hình qua IIS Manager

| Bước | Thao tác | Chi tiết |
|---|---|---|
| 1 | Mở IIS Manager | Chạy `inetmgr` với quyền Administrator |
| 2 | Chọn server gốc | Click vào tên server ở pane bên trái |
| 3 | FTP Firewall Support | Double-click biểu tượng "FTP Firewall Support" |
| 4 | Data Channel Port Range | Nhập dải port: `50000-50100` |
| 5 | External IP Address | Nhập địa chỉ IP public của FTP server |
| 6 | Apply | Nhấn "Apply" ở góc trên phải |

![Cấu hình FTP Firewall Support trong IIS Manager](https://github.com/user-attachments/assets/af120cd7-262a-486c-bfa2-d84999662665)

#### Bước 2: Cấu hình bằng PowerShell

Chạy PowerShell với quyền Administrator:

```powershell
# Đặt dải port passive cho FTP
Set-WebConfiguration /system.ftpServer/firewallSupport -Value @{
    lowDataChannelPort  = 50000;
    highDataChannelPort = 50100
}

# Khởi động lại dịch vụ FTP
Restart-Service ftpsvc

# Kiểm tra trạng thái dịch vụ
Get-Service ftpsvc
```

![Kết quả cấu hình Passive Mode bằng PowerShell](https://github.com/user-attachments/assets/728e16eb-043d-42b2-a751-ae43a95a8a02)

#### Bước 3: Cấu hình Windows Firewall

Chạy các lệnh sau với quyền Administrator trong PowerShell để mở các port cần thiết:

```powershell
# Cho phép port 21 (FTP Control)
New-NetFirewallRule -Name 'FTP-Control' -DisplayName 'FTP Control Port' `
  -Protocol TCP -LocalPort 21 -Action Allow -Direction Inbound
```

![Tạo rule firewall cho port FTP Control](https://github.com/user-attachments/assets/269418e8-0ed9-4192-ab3c-95041ff632db)

```powershell
# Cho phép dải port passive (50000–50100)
New-NetFirewallRule -Name 'FTP-Passive' -DisplayName 'FTP Passive Ports' `
  -Protocol TCP -LocalPort 50000-50100 -Action Allow -Direction Inbound
```

### 5. Quản lý FTP User trên Windows

Tạo tài khoản user và phân quyền thư mục bằng PowerShell (quyền Administrator):

```powershell
# Tạo local user với mật khẩu
$Password = ConvertTo-SecureString 'MatKhau123!' -AsPlainText -Force
New-LocalUser -Name 'ftpuser' -Password $Password -FullName 'FTP User'
```

![Tạo local user ftpuser](https://github.com/user-attachments/assets/96c775fe-0d3d-4e7b-aab1-e6115382864e)

```powershell
# Phân quyền Full Control cho user trên thư mục FTP
icacls C:\FTPRoot /grant "ftpuser:(OI)(CI)F" /T
```

![Kết quả phân quyền thư mục FTPRoot](https://github.com/user-attachments/assets/ba16cba2-b44f-418b-b35a-6896ff4ad65b)

> **Giải thích lệnh icacls:** `(OI)` là Object Inherit (áp dụng cho file trong thư mục), `(CI)` là Container Inherit (áp dụng cho các thư mục con), `F` là Full Control. Tham số `/T` áp dụng quyền cho tất cả file và thư mục con.

## Tổng kết và So sánh

### So sánh vsftpd (Ubuntu) và IIS FTP (Windows)

| Tiêu chí | vsftpd (Ubuntu) | IIS FTP (Windows) |
|---|---|---|
| Hệ điều hành | Ubuntu / Debian / RHEL | Windows Server / 10 / 11 Pro |
| Chi phí | Miễn phí (Open Source) | Tích hợp sẵn trong Windows (không phát sinh thêm phí) |
| Giao diện quản trị | File cấu hình văn bản (CLI) | IIS Manager (GUI) kết hợp PowerShell (CLI) |
| Hiệu năng | Rất cao, tiêu tốn tài nguyên thấp | Tốt, có overhead từ IIS |
| Bảo mật | Rất cao, hỗ trợ SSL/TLS | Tốt, tích hợp Active Directory |
| Cấu hình Passive Mode | Chỉnh sửa trong vsftpd.conf | IIS Manager và/hoặc PowerShell |
| Phù hợp nhất | Server Linux, Cloud, môi trường DevOps | Môi trường doanh nghiệp Windows, tích hợp AD |

### Nhận xét

Cả hai giải pháp đều đáp ứng tốt nhu cầu chia sẻ file qua FTP. vsftpd trên Ubuntu phù hợp với các hệ thống Linux và môi trường DevOps nhờ cấu hình linh hoạt bằng file text và hiệu năng cao. IIS FTP trên Windows phù hợp hơn trong môi trường doanh nghiệp đã sử dụng hệ sinh thái Microsoft, đặc biệt khi cần tích hợp với Active Directory để quản lý người dùng tập trung. Trong thực tế, việc lựa chọn giải pháp nào phụ thuộc vào hạ tầng hệ điều hành hiện có và yêu cầu tích hợp của tổ chức.
