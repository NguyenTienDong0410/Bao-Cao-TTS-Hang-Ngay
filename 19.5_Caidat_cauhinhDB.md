## III. Cài Đặt và Cấu Hình

### 3.1. Yêu cầu hệ thống phần cứng

Yêu cầu phần cứng phụ thuộc vào quy mô triển khai, loại workload và lượng dữ liệu. Dưới đây là mức khuyến nghị cho môi trường development và production nhỏ:

| Thành phần | MySQL/MariaDB | MSSQL | MongoDB | Redis |
|---|---|---|---|---|
| **CPU** | 2+ cores | 4+ cores | 2+ cores | 1+ core |
| **RAM (Dev)** | 1 GB | 2 GB | 1 GB | 512 MB |
| **RAM (Prod)** | 8–32 GB | 16–64 GB | 8–32 GB | Bằng dataset |
| **Disk (Dev)** | 10 GB | 20 GB | 10 GB | 2 GB |
| **Disk (Prod)** | SSD, 100 GB+ | SSD, 100 GB+ | SSD, 100 GB+ | SSD (nếu persist) |
| **Network** | 1 Gbps | 1 Gbps | 1 Gbps | 1 Gbps |
| **OS** | Linux/Windows | Windows/Linux | Linux/Windows | Linux |

**Lưu ý quan trọng về phần cứng:**
- Ưu tiên **RAM lớn** cho tất cả DBMS vì buffer pool/cache quyết định phần lớn hiệu năng.
- Sử dụng **SSD NVMe** thay vì HDD để giảm I/O latency đáng kể.
- Với Redis, toàn bộ dataset phải vừa trong RAM, vì vậy cần tính toán kỹ dung lượng.
- Tách riêng đĩa lưu data và đĩa lưu log để tránh tranh chấp I/O.

### 3.2. MySQL / MariaDB

#### Cài đặt trên Ubuntu/Debian


#### Cấu hình tối ưu hiệu năng

File cấu hình chính: `/etc/mysql/mysql.conf.d/mysqld.cnf` (Ubuntu) hoặc `/etc/my.cnf` (CentOS)

```ini
[mysqld]
# ===== InnoDB Buffer Pool =====
# Đặt khoảng 70-80% RAM hệ thống
innodb_buffer_pool_size = 8G

# Số lượng buffer pool instances (tăng song song)
innodb_buffer_pool_instances = 8

# ===== InnoDB Log =====
# Tăng log file để giảm checkpoint frequency
innodb_log_file_size = 1G
innodb_log_buffer_size = 64M

# ===== Connections =====
max_connections = 500
thread_cache_size = 50

# ===== Query Cache (MySQL 5.7 trở về trước) =====
query_cache_type = 0
query_cache_size = 0

# ===== Temporary Tables =====
tmp_table_size = 256M
max_heap_table_size = 256M

# ===== Slow Query Log =====
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2

# ===== Binary Log (cho Replication) =====
server_id = 1
log_bin = /var/log/mysql/mysql-bin.log
binlog_expire_logs_seconds = 604800  # 7 ngày
sync_binlog = 1

# ===== I/O =====
innodb_flush_method = O_DIRECT
innodb_flush_log_at_trx_commit = 1
```

### 3.3. Microsoft SQL Server (MSSQL)

#### Cài đặt trên Windows Server

Tải SQL Server Installer từ trang chính thức của Microsoft. Quá trình cài đặt qua giao diện đồ họa:

1. Chạy `setup.exe` với quyền Administrator
2. Chọn loại cài đặt: **New SQL Server stand-alone installation**
3. Chọn Edition: Developer (miễn phí cho dev), Express (miễn phí, giới hạn 10GB), hoặc nhập Product Key cho Standard/Enterprise
4. Chấp nhận License Terms
5. Chọn Features: Database Engine Services (bắt buộc), SQL Server Replication, Full-Text Search, Analysis Services (tùy chọn)
6. Cấu hình Instance: Default Instance (`MSSQLSERVER`) hoặc Named Instance
7. Cấu hình Service Accounts và Collation
8. Chọn Authentication Mode: **Mixed Mode** (SQL Server + Windows Authentication) và đặt mật khẩu SA
9. Hoàn tất cài đặt

#### Cài đặt trên Linux (Ubuntu)

```bash
# Import Microsoft GPG key
curl https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -

# Thêm SQL Server repository
sudo add-apt-repository "$(curl https://packages.microsoft.com/config/ubuntu/20.04/mssql-server-2022.list)"
```

### 3.4. MongoDB ()

#### Cài đặt trên Ubuntu

```bash
# Import GPG key
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | \
   sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor

# Thêm repository
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] \
https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | \
sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

# Cài đặt
sudo apt update
sudo apt install -y mongodb-org

# Khởi động dịch vụ
sudo systemctl start mongod
sudo systemctl enable mongod

# Kiểm tra trạng thái
sudo systemctl status mongod

# Kết nối vào MongoDB shell
mongosh
```

#### Cấu hình tối ưu hiệu năng

File cấu hình chính: `/etc/mongod.conf`

```yaml
# Cấu hình lưu trữ
storage:
  dbPath: /var/lib/mongodb
  journal:
    enabled: true
  engine: wiredTiger
  wiredTiger:
    engineConfig:
      # Cache size = khoảng 50% RAM hệ thống (mặc định là 50% RAM - 1GB)
      cacheSizeGB: 8
      journalCompressor: snappy
    collectionConfig:
      blockCompressor: snappy
    indexConfig:
      prefixCompression: true

# Cấu hình log
systemLog:
  destination: file
  logAppend: true
  path: /var/log/mongodb/mongod.log
  verbosity: 0

# Cấu hình mạng
net:
  port: 27017
  bindIp: 127.0.0.1  # Chỉ lắng nghe localhost (bảo mật)
  # Để cho phép kết nối từ xa: bindIp: 0.0.0.0

# Cấu hình tiến trình
processManagement:
  timeZoneInfo: /usr/share/zoneinfo

# Cấu hình bảo mật
security:
  authorization: enabled  # Bật xác thực

# Cấu hình replication (nếu dùng Replica Set)
replication:
  replSetName: "rs0"

# Giới hạn connection
net:
  maxIncomingConnections: 1000
```

Cấu hình hệ điều hành để tối ưu MongoDB:

```bash
# Tắt Transparent Huge Pages (THP) - MongoDB khuyến nghị tắt
echo 'never' | sudo tee /sys/kernel/mm/transparent_hugepage/enabled
echo 'never' | sudo tee /sys/kernel/mm/transparent_hugepage/defrag

# Tăng giới hạn file mô tả
echo "mongod soft nofile 64000" | sudo tee -a /etc/security/limits.conf
echo "mongod hard nofile 64000" | sudo tee -a /etc/security/limits.conf

# Cấu hình vm.swappiness
echo "vm.swappiness = 1" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

#### Cấu hình bảo mật cơ bản

```javascript
// Kết nối vào mongosh (lần đầu chưa có xác thực)
// mongosh

// Tạo user quản trị

  pwd: "StrongAdminPassword@123",

    { role: "userAdminAnyDatabase", db: "admin" },

  ]

// Tạo user cho ứng dụng cụ thể

  user: "appUser",

// Tạo user chỉ đọc

  user: "readonlyUser",

  roles: [
    { role: "read", db: "myAppDB" }
```

### 3.5. Redis

#### Cài đặt trên Ubuntu

```bash
# Cách 1: Cài từ package manager (phiên bản cũ hơn)
sudo apt update
sudo apt install -y redis-server

# Cách 2: Cài Redis mới nhất từ official repository
curl -fsSL https://packages.redis.io/gpg | sudo gpg --dearmor -o /usr/share/keyrings/redis-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/redis-archive-keyring.gpg] https://packages.redis.io/deb $(lsb_release -cs) main" | \
sudo tee /etc/apt/sources.list.d/redis.list
sudo apt update
sudo apt install -y redis

# Khởi động dịch vụ
sudo systemctl start redis-server
sudo systemctl enable redis-server

# Kiểm tra trạng thái
redis-cli ping
# Kết quả mong đợi: PONG
```

#### Cấu hình tối ưu hiệu năng

File cấu hình chính: `/etc/redis/redis.conf`

```bash
# ===== Mạng =====
bind 127.0.0.1          # Chỉ lắng nghe localhost (bảo mật)
port 6379
protected-mode yes

# ===== Bộ nhớ =====
# Giới hạn tổng RAM Redis được phép sử dụng
maxmemory 4gb

# Chính sách eviction khi đầy memory
# allkeys-lru: xóa key ít dùng nhất (phù hợp cache thuần)
# volatile-lru: chỉ xóa key có TTL, dùng LRU
# noeviction: trả lỗi khi đầy (phù hợp lưu trữ lâu dài)
maxmemory-policy allkeys-lru

# ===== Persistence =====
# RDB Snapshots
save 900 1       # Lưu nếu có ít nhất 1 thay đổi trong 900 giây
save 300 10      # Lưu nếu có ít nhất 10 thay đổi trong 300 giây
save 60 10000    # Lưu nếu có ít nhất 10000 thay đổi trong 60 giây

# Tên file RDB
dbfilename dump.rdb
dir /var/lib/redis

# AOF (Append Only File) - an toàn hơn RDB
appendonly yes
appendfilename "appendonly.aof"
appendfsync everysec    # everysec: cân bằng giữa an toàn và hiệu năng
                        # always: an toàn nhất nhưng chậm nhất
                        # no: nhanh nhất nhưng có thể mất dữ liệu

# ===== Lazy Deletion =====
lazyfree-lazy-eviction yes
lazyfree-lazy-expire yes
lazyfree-lazy-server-del yes

# ===== Số lượng databases =====
databases 16

# ===== Connection =====
maxclients 10000
timeout 300          # Đóng kết nối idle sau 300 giây

# ===== Log =====
loglevel notice
logfile /var/log/redis/redis-server.log
```

Cấu hình hệ điều hành cho Redis:

```bash
# Tắt THP (bắt buộc để tránh latency spikes)
echo never | sudo tee /sys/kernel/mm/transparent_hugepage/enabled

# Tắt overcommit memory (Redis yêu cầu khi dùng persistence)
echo "vm.overcommit_memory = 1" | sudo tee -a /etc/sysctl.conf
sudo sysctl vm.overcommit_memory=1

# Tăng backlog kết nối
echo "net.core.somaxconn = 65535" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

#### Cấu hình bảo mật cơ bản

```bash
# Trong /etc/redis/redis.conf

# 1. Đặt mật khẩu (requirepass)
requirepass YourStrongRedisPassword@123

# 2. Đổi tên hoặc vô hiệu hóa các lệnh nguy hiểm
rename-command FLUSHALL ""          # Vô hiệu hóa hoàn toàn
rename-command FLUSHDB ""
rename-command DEBUG ""
rename-command CONFIG "CONFIG_b4f8e2a1"  # Đổi tên thành chuỗi khó đoán
rename-command KEYS ""              # Nguy hiểm trên production lớn
rename-command SHUTDOWN SHUTDOWN_SAFE_9x2

# 3. Giới hạn bindIp
bind 127.0.0.1 192.168.1.10        # Chỉ cho phép IP nội bộ

# 4. Bật protected-mode
protected-mode yes
```

Kết nối Redis CLI với mật khẩu:

```bash
# Kết nối và xác thực
redis-cli -h 127.0.0.1 -p 6379
AUTH YourStrongRedisPassword@123

# Hoặc một lệnh
redis-cli -h 127.0.0.1 -p 6379 -a YourStrongRedisPassword@123

# Kiểm tra thông tin server
INFO server
INFO memory
INFO stats
```

Cấu hình tường lửa cho Redis:

```bash
# Chỉ cho phép IP application server kết nối vào Redis
sudo ufw allow from 192.168.1.100 to any port 6379
sudo ufw deny 6379
```
